# Pharmacy DIR Fee & Rebate Recovery

Recalculate retroactive pharmacy adjustments and recover fees or rebates not supported by contract and performance data.

**Primary buyer:** Retail and specialty pharmacy groups. **Evidence:** PBM agreements, network amendments, prescriptions, adjudication responses, performance scores, DIR fees, GER guarantees, rebates, remittances, and disputes.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- PBM contract library
- Network amendment control
- Prescription claim ingestion
- Performance measure calculation
- DIR estimate accrual
- DIR fee recalculation
- GER guarantee analysis
- Brand generic mix validation
- Network rebate calculation
- Remittance adjustment matching
- Negative balance review
- Pharmacy dispute package
- PBM response workflow
- Cash credit reconciliation
- PBM store analytics

Run `./start.sh`, then open <http://127.0.0.1:4646>. API: `5646`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
